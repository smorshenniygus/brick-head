# Собери себя сам

Подарок на день рождения: 3D-голова из 516 кубиков, которую нужно собрать
по шагам из высыпанной на стол кучи. Чистый статический сайт — `index.html`
(three.js с CDN) и `model.js` (скульпт головы и раскладка на кирпичики).

- Имя именинника передаётся в ссылке: `?name=Саша`.
- Прогресс хранится в браузере (localStorage), у каждого устройства свой.

Локально: `python3 -m http.server` в этой папке и открыть `http://localhost:8000`.
